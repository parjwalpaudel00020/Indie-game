# Pixel Play — Indie Game Picks

A responsive, beginner-friendly website project for the Web Development Assignment.

## Files
- `index.html` — semantic page structure and content
- `styles.css` — layout, colors, responsive styles, and mobile media queries
- `script.js` — dark-mode toggle and suggestion form interaction
- `images/` — folder reserved for any images you add later

## Run locally
Open `index.html` in a web browser. No installation is required.

## GitHub submission
1. Create a new GitHub repository named `pixel-play`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `images` folder.
3. Make meaningful commits as you work.
4. Copy the repository URL for your assignment submission.

The website uses original sample copy and CSS-made decorative artwork. Google Fonts are loaded online; system fallback fonts are provided.
